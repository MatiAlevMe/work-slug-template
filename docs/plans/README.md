# plans/ — especificaciones aprobadas

- Convención: `YYYY-MM-DD-<tema>.md`.
- Una especificación por archivo.
- Cada spec incluye alcance, criterios de aceptación, repos afectados y decisiones abiertas.
- No se reescriben sin autorización.
- Cuando el trabajo se cierra, se archivan en `../archive/`.

Una spec no es un tablero de progreso. El estado vive en el handoff del slug.
