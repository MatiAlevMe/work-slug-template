# domains/ — mapas técnicos

Módulo opcional para mapas técnicos por dominio o módulo.

- Cada dominio puede tener `structure.md` con límites, entradas, salidas y dependencias.
- Se actualiza en el mismo commit que el cambio.
- No duplica `PROJECT_CONTEXT.md`; solo detalla.
- Si no se usa, borrar esta carpeta y quitar las referencias.

Ejemplo: `docs/domains/<dominio>/structure.md`.
