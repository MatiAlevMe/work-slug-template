# guides/ — procedimientos

Módulo opcional para procedimientos de desarrollo, operación, despliegue o uso.

- Un archivo por procedimiento, con nombre ASCII.
- Se actualiza cuando cambia el procedimiento.
- No guarda estado ni bitácora.
- Si no se usa, borrar esta carpeta y quitar las referencias de `docs/README.md` y `AGENTS.md`.

Ejemplos: `desarrollo-local.md`, `despliegue.md`, `operacion.md`.
