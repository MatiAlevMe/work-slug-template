# knowledge/ — memoria durable

Módulo opcional para lecciones, patrones, incidentes y referencia.

- Un archivo por tema, con nombre ASCII.
- Se actualiza cuando aparece una lección reutilizable.
- No guarda datos personales ni secretos.
- Si no se usa, borrar esta carpeta y quitar las referencias.

Ejemplos: `patrones-de-error.md`, `incidentes.md`, `decisiones-tecnicas.md`.
